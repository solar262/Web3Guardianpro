3. Reentrancy Finding Template

Title: Reentrancy risk in [function]
Severity: High
Summary: The function performs an external call before updating internal accounting/state.
Impact: An attacker-controlled contract may re-enter the function and withdraw or manipulate state before balances are updated.
PoC outline:
1. Deploy attacker contract.
2. Trigger vulnerable function.
3. Re-enter through receive/fallback.
Remediation: Apply checks-effects-interactions, update state before external calls, and use ReentrancyGuard where appropriate.

4. Access Control Finding Template

Title: Missing access control on privileged function
Severity: Critical/High
Summary: A sensitive function can be called by unauthorized users.
Impact: Unauthorized users may change configuration, withdraw funds, mint tokens, pause contracts, or modify critical state.
Remediation: Add onlyOwner, role-based checks, multisig governance, or explicit authorization controls.
