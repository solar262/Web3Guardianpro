2. Account Management

Profile Settings

To manage your account settings:

  1. Navigate to the Dashboard
  2. Click on the "Settings" tab in the sidebar
  3. Update your personal information, including name, email, and company

  1. Go to the "Settings" tab
  2. Under "Security", check "Enable Two-Factor Authentication"
  3. Follow the prompts to set up 2FA using your preferred authenticator app

Team Management

Enterprise plan subscribers can add team members:

  1. In Settings, navigate to "Team Management"
  2. Click "Add Team Member"
  3. Enter the team member's email and assign appropriate permissions
  4. An invitation will be sent to join your organization

5. Smart Contract Scanner

Scanning Methods

You can scan smart contracts using various methods:

  • File Upload - Upload Solidity (.sol) files directly
  • Code Paste - Paste contract code into the scanner
  • GitHub Repository - Connect to GitHub to scan repositories
  • Ethereum Address - Scan deployed contracts by address

Performing a Scan

To scan a smart contract:

  1. Navigate to "Contract Scanner" in the sidebar
  2. Select your preferred input method
  3. Provide the contract code or information
  4. Select the vulnerabilities to scan for
  5. Click "Start Scan"

Understanding Results

Scan results are categorized by severity:

  • Critical - Severe vulnerabilities that must be addressed immediately
  • High - Important issues that pose significant risk
  • Medium - Moderate issues that should be addressed
  • Low - Minor issues with limited risk
  • Informational - Suggestions and best practices

Sample Analysis

Example output for a scanned contract:

// Security Analysis for TokenSwap.sol
// Overall Score: 85/100

- Reentrancy vulnerability at line 42
  Recommendation: Implement checks-effects-interactions pattern

Medium Risk Issues: 2

- Missing event emission at line 102
  Recommendation: Emit events for state changes

Low Risk Issues: 3
- Gas optimization opportunities
- Consider using SafeMath
- Update Solidity version

8. Vulnerability Types

Common Vulnerabilities

Web3 Security Pro detects the following vulnerability types:

Reentrancy Attacks

Detects when contracts fail to update state before transferring control to external contracts.

// Vulnerable Example
function withdraw(uint amount) public {
    require(balances[msg.sender] >= amount);
    // Vulnerable: External call before state update
    (bool success, ) = msg.sender.call{value: amount}("");
    require(success);
    balances[msg.sender] -= amount;
}

// Fixed Example
function withdraw(uint amount) public {
    require(balances[msg.sender] >= amount);
    // Fixed: State updated before external call
    balances[msg.sender] -= amount;
    (bool success, ) = msg.sender.call{value: amount}("");
    require(success);
}

Integer Overflow/Underflow

Identifies arithmetic operations that could overflow or underflow without proper checks.

Access Control Issues

Detects missing or improper authorization checks in sensitive functions.

Unchecked External Calls

Finds external calls without proper return value checking.

Front-Running Vulnerabilities

Identifies functions susceptible to front-running attacks.

DOS Vulnerabilities

Detects patterns that could lead to denial-of-service conditions.

Gas Optimization Issues

Suggests improvements to reduce gas consumption.

Advanced Detection

Enterprise plan users receive additional advanced vulnerability detection capabilities, including custom vulnerability patterns and project-specific rule sets.

9. API Integration

API Overview

Pro and Enterprise users can integrate Web3 Security Pro into their development workflow using our API:

Authentication

To authenticate API requests, you'll need to generate an API key:

  1. Navigate to Settings > API Access
  2. Click "Generate API Key"
  3. Store this key securely
  4. Include the key in all API requests as a header: X-API-KEY: your_api_key

Sample API Request

// Request to scan a smart contract
POST https://api.web3securitypro.tech/v1/scan
Headers:
  X-API-KEY: your_api_key
  Content-Type: application/json

Body:
{
  "source": "contract Token { ... }", 
  "filename": "Token.sol",
  "scanType": "comprehensive",
  "network": "ethereum"
}

Continuous Integration

Enterprise users can integrate Web3 Security Pro into CI/CD pipelines:

  • GitHub Actions integration
  • GitLab CI/CD pipeline support
  • Jenkins plugin
  • CLI tool for automated scanning

For complete API documentation, visit the API Reference page.

Our security scanner achieves over 95% accuracy in detecting common vulnerabilities. However, we recommend manual review of critical contracts in addition to automated scanning for comprehensive security.

Is my code kept confidential?

Yes, all code submitted to Web3 Security Pro is encrypted in transit and at rest. We do not share your code with third parties. Enterprise customers can request on-premises deployment for additional security.

Can I scan contracts written in languages other than Solidity?

Currently, we support Solidity, Vyper, and Move programming languages. Support for additional languages is under development.

Our security rules database is updated weekly to include the latest vulnerabilities and attack vectors discovered in the Web3 space.
